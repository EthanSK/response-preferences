What the viewer can and cannot do

The generated page is a snapshot; it does not watch disk changes. A snapshot cannot silently overwrite its source. Open file can enable direct saving through the browser’s file picker. Otherwise, use Download copy.

It supports UTF-8 text up to 5 MB. Markdown, JavaScript, TypeScript, Python, JSON, HTML, CSS, SQL, YAML, shell, Rust and Go have editor syntax colours. Other text opens without language highlighting. This is a document editor, with no terminal or code execution.

Raw HTML in Markdown is escaped. Remote images do not load. Local raster images are embedded best effort by the generator. The self-contained page includes its source text, so keep private documents and their viewers private.

Browser and Codex rendering vary. The native file viewer is still available as a fallback.

Clone into your skills folder, then tell your AGENTS file to use it. Keep the defaults, or change the preferences to fit you.

Read the full skill ↗

1. Install the skill

git clone https://github.com/EthanSK/response-preferences.git ~/.codex/skills/response-preferences

2. Add to your AGENTS.md

Use $response-preferences for all replies.

Python 3.9+ generates viewers. No Node build is needed to use the included template. Keep an existing skill folder; do not overwrite it blindly.

Notifications and other integrations

The skill defines short notification titles, summaries and status icons. Native delivery uses a separate local integration and is not installed by this repository. Notification display duration remains controlled by your app and operating system.

The response rules work as agent instructions. They do not modify Codex itself, guarantee perfect model compliance, or install an app extension.

Build, adapt, or contribute

The source and MIT licence are on GitHub. The README explains every feature and the build commands. Public demos use fictional messages. No conversations, screenshots, credentials or private notification hooks are included.
