# Desktop assets

The macOS Tahoe default aerial wallpaper is Apple’s artwork, exported by macOS as DefaultAerial.jpg. Apple lists Tahoe as the current public release: https://support.apple.com/en-us/109033 (checked 7 September 2026). App icons were obtained from the installed applications for this personal setup showcase. Their names, logos and artwork belong to their respective owners; they are not licensed under this repository’s MIT code licence. Links in apps.json point to their publishers, documentation or Ethan’s public forks. No endorsement is implied.

The desktop is a visual demonstration. The Dock order comes from the 7 September 2026 setup. The additional menu-bar applications come from the 25 August 2026 ultrawide reference and saved app settings. The reference screenshots, personal file paths, unread counts and private configuration are not included. Native status symbols are drawn for this demonstration; they do not report a visitor’s computer state.

Personal Dock folders and the local-only media-key helper are omitted from the shared demo. Menu-bar app icons link to Menu Bar Dock; the app directory and Dock keep the individual publishers’ links.
